# Security

## Reporting a problem

Please **do not** open a public issue for a security problem.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and click **Report a vulnerability**. You will get a reply within a week.

## How Deepcus handles your data

- All tasks, habits, goals and history are stored locally in `%LOCALAPPDATA%\FocusOS`.
- Google sign-in uses the official OAuth flow in your browser. Deepcus asks only for your email, your name and read-only calendar access. The token is stored locally and deleted when you sign out.
- Updates are downloaded from this repository's Releases only. Each installer is checked against its published SHA-256 before it runs.

## Supported versions

Only the latest release gets fixes. Deepcus updates itself, so most people are always on it.
